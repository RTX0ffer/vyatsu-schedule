# Автоматическое расписание ВятГУ 📅

Автоматический парсинг двухнедельного расписания с сайта ВятГУ, ежедневное ночное обновление календарей (.ics) через GitHub Actions и умный Telegram-бот.

## 🚀 Как это устроено
1. **GitHub Actions** каждую полночь в 00:00 (МСК) запускает [`make_ics.py`](make_ics.py).
2. **Auto-Discovery**: скрипт автоматически сканирует страницу расписания ВятГУ, находит все актуальные группы поддерживаемых направлений (даже при смене учебного года, смещении курсов или открытии новых групп) и сохраняет их в `groups.json`.
3. Скрипт скачивает актуальные PDF, парсит занятия и обновляет `lessons_cache.json` и календари в каталоге `calendars/`. Устаревшие календари выпустившихся групп автоматически удаляются.
4. Файлы коммитятся обратно в репозиторий.
5. **Смартфон** автоматически обновляет календарь по подписке на `.ics`.
6. **Telegram-бот** динамически подтягивает список групп и расписание, отправляет пары в чат и файлы календаря для импорта в 1 клик.

## 📲 Как подписаться на календарь со смартфона

Ссылка на календарь (например, для ПМИб-1301):
```
https://cdn.jsdelivr.net/gh/<ВАШ_GITHUB_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>@main/calendars/pmib/vyatsu_1301.ics
```
*(Либо персональная ссылка для вашей группы из меню бота `/calendar`)*

### iPhone (Apple Calendar):
1. Откройте Safari и вставьте ссылку с протоколом `webcal://`:
   `webcal://cdn.jsdelivr.net/gh/<ЛОГИН>/<РЕПОЗИТОРИЙ>@main/calendars/pmib/vyatsu_1301.ics`
2. Нажмите «Подписаться» и укажите автообновление (например, каждый день).

### Android / Google Календарь:
1. Зайдите в веб-версию [Google Календаря](https://calendar.google.com/) с компьютера.
2. Слева у блока «Другие календари» нажмите **«+»** ➔ **«Добавить по URL»**.
3. Вставьте ссылку на нужный `.ics` файл из папки `calendars/`.

## 🤖 Деплой бота на Render.com

В панели управления **Render**:
1. В разделе **Environment Variables** добавьте:
   * `BOT_TOKEN`: токен от `@BotFather`
   * `DATA_URL`: `https://raw.githubusercontent.com/<ЛОГИН>/<РЕПОЗИТОРИЙ>/main/lessons_cache.json`
   * `ICS_URL`: `https://cdn.jsdelivr.net/gh/<ЛОГИН>/<РЕПОЗИТОРИЙ>@main/calendars/pmib/vyatsu_1301.ics`
2. Бот автоматически готов к работе 24/7!
